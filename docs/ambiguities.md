# Rules Ambiguity Register

This register separates approved decisions from questions that still need a ruling.

## Approved decisions

1. Favor Update: the player enters only the final Favor change. The app does not track Performance or roll the end-of-session d10.
2. Group Favor: the app does not track Group Favor.
3. Starting skill ranks: before spending XP, the player chooses four career skills and two starting-specialization skills, gaining one free rank in each selection, subject to the character-creation rank cap.
4. Starting money: each new character receives 500 credits to spend on starting equipment.
5. Specialization acquisition: use the standard escalating formula. A new specialization costs 10 XP times the total number of specializations the character will own after purchase, plus 10 XP when it is outside the character's career. Universal Agent specializations count as in-career.
6. Attachments: players may install attachments on eligible owned items. The app tracks and enforces available hard points and applies each installed attachment's base deterministic effects. Optional attachment modification upgrades are outside the first complete release.
7. Gear access: Controlled gear uses the Ordinary +0 Favor access modifier, Restricted gear uses +2, and Advanced gear cannot be obtained through normal cash or Favor acquisition. Advanced gear enters inventory only as a reward or through GM/manual assignment. Items specifically designated Illegal use +4.
8. Tree direction: every printed connector is mechanically two-way. A purchased node makes any directly connected node eligible, regardless of relative row or column.

## Open questions

1. Descriptions: final player-facing career and specialization descriptions are not present on the mechanical tree pages. Use the approved omnibus prose when each record is imported.
